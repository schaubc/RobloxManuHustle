Gemeinsames Roblox-Projekt (Steal-an-Egg-Spiel).

- **Code** (Luau-Skripte) liegt hier im Repo und wird mit [Rojo](https://rojo.space) in Roblox Studio synchronisiert.
- **Map** (Modelle, Welten, Deko) liegt im veröffentlichten Place und wird über **Team Create** gemeinsam bearbeitet – nicht in Git.
